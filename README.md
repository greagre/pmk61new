# pmk61 — МК-61 с расширением Б3-34 (GitHub Pages)

Эмулятор МК-61 и расширение памяти Б3-34. Чистое ядро без DOM, профили моделей,
интерфейс на настоящей технике МК-61 (журнал, шаг, самотест).

## Структура файлов

- `index.html` — оболочка приложения
- `core.js` — чистое ядро ПМК (RPN, программа, регистры), без DOM
- `profiles.js` — профили моделей (исторический МК-61, МК-61 с расширением)
- `ui.js` — интерфейс (клавиатура, регистры, программа, журнал)
- `shelf.js` — полка программ
- `ext61.js` — расширение: 4 банка × 15 регистров, 4 страницы программы,
  межбанковый доступ F0 40…4F и F0 60…6F без переключения банка
- `disasm61.js` — декодер: программа в мнемоники, команды не разрываются и не сдвигают адреса
- `ext61-ui.js` — панель «Листинг расширения» рядом со штатным листингом
- `tests.html` — проверка ядра
- `tests-ext.html` — проверка расширения
- `tests-disasm.html` — проверка декодера

## Известные ограничения ядра

1. `Re` (4E/6E) — ядро подписывает как «?», расширение понимает.
2. `A0…A4` — подпись как «A0…», обработки нет.
3. `modAddr` упрощает отрицательные адреса.
4. Переход на адрес выше 104 не отделён от «-0…-4».

## Коды расширения F0

| Код | Действие | Длина |
|:---|:---|:---|
| `F0 00…03` | выбор банка 0…3 | 2 |
| `F0 04` | номер текущего банка → X | 2 |
| `F0 05` | адрес текущего банка → X | 2 |
| `F0 06` | адрес текущего банка ← X | 2 |
| `F0 10` | номер страницы → X | 2 |
| `F0 11` | номер страницы ← X | 2 |
| `F0 20…23` | выбор страницы программы 0…3 | 2 |
| `F0 24` | номер текущей страницы → X | 2 |
| `F0 40…4F` | x→П в банк-адресат (0F — это R0) | 2 |
| `F0 60…6F` | П→x из банка-адресата (0F — это R0) | 2 |

Первый байт `F0` вместе со вторым занимают **две** ячейки программы.
Если `F0` стоит в последней ячейке, второй байт берётся с нулевого адреса — как в исполнении.

Скрипты подключаются с номером версии (`ext61.js?v=4`). GitHub Pages отдаёт файлы
из кэша до ~10 минут, а мобильный браузер держит старую копию дольше.
Поэтому меняйте число `?v=` при каждой правке — иначе легко смотреть старые
результаты и искать уже исправленные ошибки.

## Подключение расширения в интерфейсе (следующий шаг)

Сейчас `ui.js` создаёт ядро как `MKCore.create()`, поэтому `F0` в калькуляторе
считается неизвестной командой, хотя в `ext61.js` она исполняется.
Чтобы включить расширение в интерфейсе:

1. создать ядро через `MKExt61.create()` (расширение надстройкой над базой);
2. при записи `F0` резервировать вторую ячейку — иначе адреса поедут;
3. показать ожидание второго байта, как в настоящем ПМК.
